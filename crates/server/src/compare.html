FAST_LLM: one file against three

A FAST_LLM is one weights file holding a small model, a large model and the bridge between them: the small model reads your prompt, the bridge translates what it read, and the large model answers from that, reading none of the prompt itself. Ask once to see three arms side by side, all run here in Prattle's Rust: the large model alone, the same pair from its three files, and the one FAST_LLM file. The bridge method is LatentPort, by Simon Villani.
